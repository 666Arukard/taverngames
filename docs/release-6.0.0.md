# TavernGames 6.0.0

## Deutsch

Freie Spielnamen sind jetzt regulär verfügbar. Die Namensverwaltung bietet eine Spielauswahl mit Kategorieicon und eine zweispaltige Sammelbearbeitung. Dame, Schere Stein Papier, Streichholzspiel, Wettessen und Wetttrinken sind stabil. Die Restanzahl beim Streichholzspiel ist optional. Neue Beta: Schiffe versenken auf einem 10×10-Feld mit verdeckten Flotten, manueller Spielerplatzierung und automatischer Platzierung ausschließlich durch die SL beziehungsweise für automatische NPCs.

- 32 stabile Spiele und vier stabile Turniere; nur Schiffe versenken benötigt den Beta-Schalter.
- Spielnamen ohne Beta-Schalter: Einzelbearbeitung über Dropdown mit Kategorieicon, zweispaltige Sammelbearbeitung, Standardnamen wiederherstellen und temporäre Partienamen. Suche mit Original- und Wunschnamen bleibt möglich.
- Schiffe versenken (Beta): fünf Schiffe auf 10×10, kein Berühren, verdeckte Flotten, Treffer-Zusatzzug optional, Serien und interne Spieltoken. Spieler platzieren manuell und bestätigen selbst; automatische SL-Platzierung bestätigt nicht für Spieler. Automatische NPCs stellen selbst auf und verwenden keine verdeckten Gegnerpositionen. Optionale SL-Einsicht bleibt nur der SL zugänglich.
- Streichholz-Restanzahl standardmäßig sichtbar, durch die SL abschaltbar; Fünferblöcke bleiben erhalten.

Benötigt Foundry VTT ab 14.369. Nach dem Update alle Clients neu laden. Automatisierte Regeln und DE/EN-Zweiclient-Browserprüfungen laut Entwickler mit Foundry-Testdoubles geprüft; keine neue echte Foundry-Abnahme. Acht geprüfte englische Anleitungen bleiben verfügbar; die neue englische Anleitung wartet auf Review. Keine Charakter-Geldbuchungen oder neuen Bilddateien.

## English

Custom game names are now a regular feature, with a game selector, category icons and a two-column bulk editor. Checkers, Rock Paper Scissors, the Matchstick Game, Eating Contest and Drinking Contest are stable. The remaining match count is optional. New beta: Battleship on a 10×10 board with hidden fleets, manual player placement and automatic placement restricted to the GM or automatic NPCs.

- 32 stable games and four stable tournaments; only Battleship requires the Beta switch.
- Game names no longer need a Beta switch: edit individually with a game selector and category icon or use the two-column bulk editor. Restore original names and set temporary session names. Both original and custom names remain searchable.
- Battleship (Beta): five non-touching ships on a 10×10 board, hidden fleets, optional extra turn on a hit, series and internal game tokens. Players place ships manually and confirm their own fleet. GM automatic placement does not confirm for players. Automatic NPCs place their own fleets and never use hidden enemy positions. Optional GM fleet visibility is restricted to the GM.
- The remaining matchstick count is visible by default and can be disabled by the GM; five-stick groups remain.

Requires Foundry VTT 14.369 or later. Reload all clients after updating. The developer checked automated rules and DE/EN two-client browser flows with Foundry doubles; no new live Foundry certification. The eight approved English guides remain available; the new English guide awaits review. No Actor currency transactions or new image assets.
