# Taverngames 1.5.0

Chō-Han ist jetzt regulär ohne Spiele-Beta-Schalter verfügbar. Straßenlotto erhält eine optionale private SL-Einsicht vor dem Aufdecken, standardmäßig ausgeschaltet. Alle neun Spiele sind stabil; die allgemeine 3D-Anbindung bleibt separat schaltbare Beta.

- Chō-Han aus dem Spiele-Beta-Schalter in das reguläre Spieleangebot übernommen.
- Straßenlotto: private SL-Einsicht per standardmäßig ausgeschaltetem Häkchen, auch ohne Teilnahme.
- Spielerwerte bleiben bis zum ausdrücklichen Aufdecken geheim.
- Allgemeine 3D-Anbindung bleibt unabhängig davon Beta; keine neue V2-Freigabe.

Chō-Han ist nach Nutzerabnahme regulär verfügbar. Straßenlotto war bereits stabil und erhält jetzt die private optionale SL-Einsicht, standardmäßig aus und auch ohne eigenen Tippschein verwendbar. Spieler sehen die Ziehung erst beim ausdrücklichen Aufdecken. Umschalten verändert weder Würfelwerte noch Auszahlungen. Ohne Dice So Nice zeigt das Moderationsfenster die private Zahl.

Alle neun Spiele sind unabhängig vom Spiele-Beta-Schalter verfügbar. Die allgemeine 3D-Anbindung bleibt separat einschaltbare Beta; keine V2-Freigabe. Bestehende Spielstände, Modul-ID und Manifest-Link bleiben erhalten. Nach Installation Welt neu laden. Keine neue eigene Foundry-Live-Abnahme durch Codex.

website.json enthält alle acht Blöcke, korrekte Eintragszahlen und auf Kernfunktionen beschränkte Beschreibungen.

## English
Cho-Han is now stable and available without the game beta setting. Street lottery gains optional private GM inspection before reveal, off by default and usable without a ticket. Players cannot see the stored result before explicit reveal. All nine games are stable; general 3D integration remains a separately enabled beta. Reload the world after installing.
