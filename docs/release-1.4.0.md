# Taverngames 1.4.0

Lügenwürfel und Drachenhort sind jetzt stabil und ohne Beta-Test-Schalter verfügbar.

Neu: separat einschaltbare Dice-So-Nice-Wurfanimationen als Beta. Die Funktion ist standardmäßig ausgeschaltet.

- Alle acht Spiele regulär verfügbar; bestehende Spielstände bleiben erhalten.
- 3D-Würfel zeigen dieselben Ergebnisse wie die Spielwertung und respektieren verdeckte Würfe.
- Dice So Nice separat installieren und aktivieren; Dice Tray wird nicht benötigt.
- Keine dauerhaft interaktiven 3D-Würfel in dieser ersten Beta.
- Überflüssige Höhenvorgaben im Katalog entfernt.

Dice So Nice muss separat installiert und aktiviert werden. Die erste Beta zeigt normale Wurfanimationen, keine dauerhaft interaktiven 3D-Würfel. Fehlendes Dice So Nice blockiert keine Spielaktionen. Keine eigene Foundry-/DSN-Live-Abnahme; 139 Modultests und zwölf synthetische Browser-Suiten im Build dokumentiert.

website.json enthält jetzt acht Blöcke: patchnotes, games, plans, plans2, functions, settings, sources und sources1.

## English
Eight stable games; separately switchable optional Dice So Nice animation beta, off by default. Scoring and animation share the same authoritative results. Private rolls are delivered only to authorized recipients. No persistent interactive dice yet. Existing saves and the GitHub update URL remain unchanged.
