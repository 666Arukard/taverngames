# Taverngames 1.2.1

Alle fünf Spiele sind regulär verfügbar: Schocken, Farkle, Schweinchen, Schiff–Kapitän–Mannschaft und Straßenlotto.

Dieses Verteilungsupdate richtet GitHub Releases als Updatequelle ein. Spielregeln, Modul-ID und bestehende Einstellungen bleiben unverändert.

Enthalten sind die Verbesserungen aus 1.2.0: automatische NPC-Zugabschlüsse nach mindestens fünf Sekunden, Schweinchen-Wurfhistorie, variable Zahlenzahl je Lotto-Tippschein und drei optionale Farkle-Hausregeln.

Foundry-Ziel: 14.369, basierend auf dem dokumentierten Nutzer-Praxistest des Basismoduls. Automatisierte Prüfungen ersetzen keine zusätzliche Live-Abnahme.

Installation nach Veröffentlichung: https://github.com/666Arukard/taverngames/releases/latest/download/module.json

Für Bestandsinstallationen muss nach erfolgreicher Veröffentlichung dasselbe Manifest zusätzlich unter der bisherigen brunecoaching.de-Adresse bereitgestellt werden. Historische Pakete bleiben erhalten.
